# 🎬 PRISM — медиаконтентті бағалау және тәуекелдерді талдау жүйесі

Медиахолдингке арналған контентті алдын ала бағалау және лицензияларды сатып алу бойынша шешім қабылдауды қолдайтын ішкі корпоративтік жүйе.

**Стек:** FastAPI + SQLAlchemy + PostgreSQL / SQLite.

## 🛠️ Технологиялар

| Құрал | Мақсаты |
| :--- | :--- |
| *FastAPI* | Жоғары өнімді REST API фреймворкі |
| *SQLAlchemy* | ORM (дерекқормен ыңғайлы жұмыс) |
| *SQLite / PostgreSQL* | Корпоративтік деректерді сақтауға арналған БД |
| *Passlib + bcrypt* | Пайдаланушы құпия сөздерін қауіпсіз хэштеу |
| *python-jose* | JWT токендер арқылы аутентификация |
| *Pydantic* | Кіріс деректерін қатаң валидациялау |

## 📁 Жоба құрылымы

```
prism/
├── app/
│   ├── main.py          # FastAPI қосымшасы, CORS және баптаулар
│   ├── database.py      # SQLAlchemy қосылымы мен сессиялар
│   ├── models.py        # ORM кестелер (User, Content, Review, DecisionLog)
│   ├── schemas.py       # Pydantic схемалары (Валидация)
│   ├── auth.py          # Парольдерді хэштеу және JWT утилиталары
│   ├── dependencies.py  # Рөлдік модельді тексеру (RBAC)
│   └── routers/
│       ├── auth.py      # POST /auth/login, POST /auth/register
│       ├── users.py     # Пайдаланушыларды басқару
│       ├── movies.py   # Фильмдер мен сериалдарды басқару (CRUD)
│       ├── reviews.py   # Секретті есептер мен бағаларды қосу (CRUD)
│       └── analytics.py # Директорға арналған күрделі аналитикалық сұраулар
├── .env.example
├── .gitignore
├── requirements.txt
└── README.md
```

## 📐 Дерекқор схемасы (ERD)

```
   [Users] ─── (1:N) ───> [Reviews] <─── (1:N) ─── [Movies]
     │                                                 │
     └──────── (1:N) ───> [DecisionLogs] <─── (1:N) ───┘

**Users:** Қызметкерлер мен Директор деректері.
**Movies:** Бағалауға жататын фильмдер мен сериалдар тізімі.
**Reviews:** Критиктердің құпия жұмыс есептері мен бағалары (1-10 балл аралығында).
**DecisionLogs:** Директордың соңғы қабылдаған шешімдерінің журналы (Сатып алу/Бас тарту негіздемесі).
```
## 👥 Рөлдер және рұқсаттар (RBAC)
| Әрекет | Қызметкер (Критик/Аудармашы) | Директор (Admin) |
|---|---|---|
| Жүйеге кіру (Логин) | ✅ | ✅ |
| Жаңа фильмдерді көру | ✅ | ✅ |
| Құпия есеп жазу және баға қою | ✅ (Тек өздігінен) | ❌ |
| Барлық қызметкерлердің есептерін оқу | ❌ | ✅ |
| Орташа балл мен аналитиканы көру | ❌ | ✅ |
| Финалдық үкім шығару (Сатып алу/Бас тарту) | ❌ | ✅ |
| Жаңа фильм картасын қосу | ❌ | ✅ |

## 🚀 Іске қосу нұсқаулығы
### 1. Репозиторийді клондау және папкаға өту
```bash
git clone [https://github.com/sizdin-username/PRISM.git](https://github.com/sizdin-username/prism.git)
cd prism
```
### 2. Виртуалды ортаны құру
```bash
python -m venv venv
# Windows үшін:
venv\Scripts\activate
# Mac/Linux үшін:
source venv/bin/activate
```
### 3. Қажетті кітапханаларды орнату
```bash
pip install -r requirements.txt
```

### 4. Орта айнымалыларын баптау
```bash
cp .env.example .env
# .env файлын ашып, SECRET_KEY мәнін өзгертіңіз
```

### 5. Серверді іске қосу
```bash
uvicorn app.main:app --reload
```

API мекенжайы: http://localhost:8000
Интерактивті құжаттама (Swagger UI): http://localhost:8000/docs

## 📡 Негізгі API Эндпоинттері

### 🔐 Аутентификация
```
POST /api/v1/auth/register — Жаңа қызметкерді тіркеу
POST /api/v1/auth/login — Жүйеге кіру (JWT токен алу)
```

### 🎬 Фильмдер (Movies)
```
GET /api/v1/content/ — Бағалауға қолжетімді фильмдер тізімі
GET /api/v1/content/{id} — Нақты фильм туралы ақпарат
POST /api/v1/content/ — Жаңа фильм картасын жасау [Admin]
PATCH /api/v1/content/{id} — Фильм мәліметтерін жаңарту [Admin]
DELETE /api/v1/content/{id} — Фильмді жүйеден өшіру [Admin]
```

### ✍️ Рецензиялар мен Есептер (Reviews)
```
POST /api/v1/reviews/ — Құпия есеп пен бағаны жіберу [User]
GET /api/v1/reviews/my — Қызметкердің өз есептерінің тізімі
GET /api/v1/reviews/{id} — Нақты есепті көру [User(өздігінен)/Admin]
DELETE /api/v1/reviews/{id} — Есепті өшіру [User(өздігінен)/Admin]
```

### 📊 Аналитика және Шешімдер
```
GET /api/v1/analytics/summary — Фильмдердің орташа балы мен жүйелік ұсыныстары [Admin]
POST /api/v1/analytics/{id}/decide — Директордың финалдық шешімін журналға жазу [Admin]
```

## Деплой (Railway)
1. Жобаның соңғы нұсқасын GitHub репозиторийіне push жасаңыз.
2. [Railway.app](https://railway.app) платформасына өтіп, аккаунтты GitHub арқылы байланыстырыңыз.
3. **"New Project"** → **"Deploy from GitHub repo"** батырмасын басып, осы `PRISM` репозиторийін таңдаңыз.
4. Ішкі дерекқорды қосу үшін: **"Add"** → **"Database"** → **"PostgreSQL"** таңдаңыз. Railway дерекқорды автоматты түрде жасап, баптауларын реттейді.
5. Жобаның баптауларында (**Variables** бөлімінде) келесі айнымалыларды көрсетіңіз:
    * `DATABASE_URL` — PostgreSQL қосылым сілтемесі (Railway оны автоматты түрде ұсынады)
   * `SECRET_KEY` — Құпия токен кілті
   * `ALGORITHM` — `HS256`
6. Платформа файлдарды өзі талдап, жобаны автоматты түрде желіге орналастырады.
